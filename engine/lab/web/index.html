    Suggestion / bug report

    Reports and suggestions go to the project's issue page on GitHub (a free GitHub account is needed). The form opens with the batch's setup and seeds already filled in, so the battles can be played again exactly.

    1. On the Results page press Save run to a file.... The file holds the exact setup, the batch seed and the seed of every battle that crashed.
    2. Press the button below. A page opens with the details filled in; add what you saw.
    3. Drag the saved file into the box on that page (it is saved as .txt, which GitHub accepts) and press Submit.
